# User guides (DEMO / TEST)

## Customer

Sign in as `customer.a`. Use Dashboard, Accounts, Transfer (review then confirm). Destination example: `1000000003`. Statements accept a date range. Log out when finished.

## Employee

Sign in as `employee`. Search customers, open accounts, filter transactions, export CSV, post a **simulated** deposit.

## Administrator

Sign in as `admin`. Review metrics, users, roles/permissions, append-only audit, settings.

Do not use real customer data or production passwords.
